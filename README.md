# Система отслеживания проникновения на запрещенную территорию

Система компьютерного зрения для мониторинга запретных зон и обнаружения людей в охраняемых областях.

## Описание проекта

Проект представляет собой систему видеонаблюдения, которая:
  - Обнаруживает людей на видео с помощью YOLO модели;
  - Определяет нахождение людей в заданных запретных зонах;  
  - Активирует сигнализацию при нарушении границ;
  - Сохраняет обработанное видео с визуализацией обнаружений.

## Функциональные возможности

- Детекция людей с помощью YOLO11n
- Определение пользовательских запретных зон через JSON;
- Система сигнализации с настраиваемой задержкой;
- Обработка видеофайлов с визуализацией результатов;
- Визуализация ограничительных зон и обнаруженных объектов.


## Метод выделения запретных зон (обоснование подхода)

Поскольку система видеонаблюдения использует стационарную камеру с фиксированным положением и углом обзора, а также учитывая специфический характер охраняемых территорий, был выбран метод ручного выделения запретных зон. Данный подход обладает следующими преимуществами.

### Преимущества ручного выделения:

1. **Высокая точность границ**
   - Возможность точного соответствия реальным физическим границам охраняемых зон;
   - Учет особенностей архитектуры и ландшафта.

2. **Адаптивность к специфическим требованиям**
   - Возможность выделения зон сложной геометрической формы;
   - Учет контекстных ограничений и особенностей объекта.

3. **Простота реализации**
   - Минимальные вычислительные затраты на этапе настройки;
   - Прозрачность и контролируемость процесса.

## Установка и запуск

### 1. Установка зависимостей

bash
pip install ultralytics opencv-python numpy

### 2. Запуск приложения

В консоли перейдите в директорию проекта, затем введите "python app" и нажмите Enter для запуска приложения.

### 3. Файлы

- app.py - основной скрипт для обработки видео "test.mp4" и преобразования в детектированный видео файл "detected_video.mp4", который использует координаты запретных зон из файла "restricted_zone.json";
- Security.py - файл, содержащий класс, объект этого класса используется в скрипе "app.py" для обработки кадров;
- test.mp4 - исходное видео;
- detected_video - детектированное видео;
- restricted_zones.json - файл содержит координаты запретных зон в виде списка списков точек многоугольника;
- в папке models хранятся модели YOLOv11.
